# 闭涛 · 书式作品集（A Flip-book Portfolio）

一本关于「学习 × 工作 × 创作」的交互翻页书式个人作品集。
纯手写 **零依赖** HTML/CSS/JavaScript 三件套，无任何框架、无构建工具、无外部 CDN，可离线打开。

## ✨ 特性

- 📖 **书的概念**：封面 → 学习（书架）→ 工作（项目文档）→ 创作（内容档案）→ 封底，共 5 页，支持翻页动画
- 🗂 **章节导航**：页眉章节跳转 + 底部翻页条 + 键盘 ←/→ + 手机左右滑动
- 🌐 **中英双语**：右上角一键切换，偏好存入 localStorage
- 🔊 **翻页音效**：WebAudio 实时合成（无音频文件），默认关闭、可一键开关
- 📚 **证书书架**：13 本「证书之书」，点击书脊放大查看扫描件
- 📄 **项目文档**：7 段经历以「工作文档 + 标签页」形式呈现
- ♿ **无障碍**：语义化标签、aria 属性、`prefers-reduced-motion` 降级、JS 禁用兜底

## 🗂 目录结构

```
book-site/
├── index.html      # 结构（5 个页面 + 灯箱 + toast）
├── style.css       # 全部样式（深墨书壳 + 米白纸页 + 琥珀点缀）
├── script.js       # 全部内容数据与交互（改内容只改这个文件）
├── resume.pdf      # 简历（封底「Read the resume」跳转目标）
└── images/         # 插画、头像、证书扫描件、社交图标
    ├── hero-wide.png   # 封面插画（AI 生成）
    ├── hero-tall.png   # 章节页插画（AI 生成）
    ├── cert-01~13.jpg  # 证书扫描件
    └── ...
```

## 🚀 本地运行

无构建步骤，任选其一：

```bash
# 方式一：直接双击 index.html
# 方式二：起本地服务（推荐，体验完整）
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## ☁️ 部署到 GitHub Pages

1. 在 GitHub 新建仓库，把本目录推上去：

```bash
git init
git add .
git commit -m "v1: 书式作品集（双语翻页书）"
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git push -u origin main
```

2. 仓库 Settings → Pages → Source 选 `main` 分支根目录，保存。
3. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。
4. 上线后记得用电脑和手机各打开一遍，逐页验收（参考 Step 6 验收清单）。

## ✏️ 改内容

所有个人资料集中在 `script.js` 顶部的数组里，改数组即可，页面自动重渲染：

| 数组 | 内容 |
|---|---|
| `CERTS` | 13 本证书书（书脊名 / 中英名 / 扫描件文件名） |
| `TIMELINE` | 时间轴节点 |
| `PROJECTS` | 7 段项目经历（标题 / 徽章 / 简介 / 工具 / 贡献） |
| `SKILLS` | 技能工具箱（4 组） |
| `CREATE` / `CREATE_STATS` | 创作档案卡片与统计 |
| `CONTACTS` | 封底联系方式（点击复制） |
